# METETL

Утилита командной строки для скачивания, обработки и анализа изображений из открытой коллекции Метрополитен-музея (The Metropolitan Museum of Art).

## Возможности

- **Подготовка метаданных** – выборка картин из CSV-файла и сохранение в JSON.
- **Скачивание и обработка** – асинхронная загрузка изображений, применение фильтров (размытие, свёртки, выравнивание гистограммы, гамма-коррекция, оператор Собеля) и сохранение результатов.
- **Статистический анализ** – вычисление среднего возраста объектов по десятилетиям поступления с доверительными интервалами и визуализация графиков.

## Требования

- Python 3.9 или выше
- CSV-файл с данными коллекции (не входит в репозиторий).  
  Скачайте [`MetObjects.csv`](https://github.com/metmuseum/openaccess) и поместите его в папку `data/`.
